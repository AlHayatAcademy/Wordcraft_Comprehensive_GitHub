# Editorial work and learner pilot

## Remaining editorial work

The inventory is not a blanket accuracy certification. Complete an individual review of the 200 topic examples, provide their Urdu translations, and produce a distinct delayed-review context for each course sense. Existing core examples still largely double as practice examples; added communication examples have a separate immediate-practice context, currently reused for delayed review. Some guided unit introductions remain outcomes/scaffolds rather than coherent authored readings. Existing antonym, synonym and family links need sense-level review beyond the named corrections; empty fields do not imply that a word has no linguistic relatives. Displayed dictionary links are reference evidence, not teaching approval.

New readings/models should be reviewed by an English–Urdu editor, especially register, prepositions, naturalness and interpretation. Have a second reviewer check a representative gold set, then expand. Never turn an old reviewed flag into proof. Keep source quotations separate from authored examples. Technical/legal/medical lessons are terminology learning, not professional advice.

The current implementation still uses existing layered route/card renderers; startup is now explicit and shared modules own content, scheduling and persistence, but a complete rendering-module refactor is future work. No IndexedDB recording archive, worker search or cross-device backend is implemented. Measure those needs before adding complexity.

## Pilot, without invented results

Recruit adult English–Urdu learners with different starting knowledge and phones/desktops. Obtain consent, allow withdrawal, and record device/browser/accessibility needs without collecting unnecessary personal data. Pilot a fixed set of lessons; log assistance, new items, due items and abandonment separately.

Test independent meaning-to-word retrieval and unfamiliar-context completion seven and thirty days after introduction. Do not show the original model first. Have two human reviewers assess productive writing/speaking for meaning, grammar, register and comprehensibility using a shared rubric; blind them to immediate scores where feasible. Report disagreement as well as agreement.

Track completion, where learners stop, time spent, reviews per day, overdue burden, errors after hints and feedback usefulness. Include a keyboard/screen-reader/zoom subgroup. State attrition, sample size, baseline knowledge and missing follow-up results. Compare lesson versions only with a predeclared allocation method. Publish measured results; do not infer proficiency gains from app counters.
