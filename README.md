# Wordcraft · revised learning edition

This is the complete static repository for the existing Wordcraft application. The original interface and toolkit remain: vocabulary search, independent filters, topic lessons, expressions, family/collocation panels, reading, spelling/listening, Writing, Speaking, local recording, bookmarks, progress and backups.

## Deploy

Extract this repository and publish its contents at the same path as your existing GitHub Pages site. Keep `.nojekyll`, `index.html`, `modules/`, `packs/`, CSS, JavaScript and JSON together. No backend, paid API, bundler or npm install is required. HTTPS is required for service workers and microphone recording; localhost is supported for development. Do not open `index.html` using `file://`.

Preserve the same origin and repository path to retain browser storage. Existing installations will offer an update button once the new worker installs. Export progress before updating or restoring a backup. The new worker does not activate automatically over an existing controlled page.

## What changed

- Shared teaching-sense resolver and stable lesson aliases. Topic and selected taxonomy meanings survive cards, practice and scheduled review. Identical core/topic definitions share a resolver identity.
- Sense progress is separate from historical word progress. Existing IDs, bookmarks, notes and source material are preserved, including aliases for dictionary headwords promoted to learning entries.
- One tested scheduling algorithm handles new/due answers, corrective same-day retries and assisted practice. Recognition, independent target recall, listening and productive drafts have separate records.
- 160 original communication senses in 20 eight-sense lessons, with English/Urdu definitions, bilingual models and separate English practice contexts. Original core and topic routes remain.
- Persistent sense-specific drafts, revision links in the notebook, restore confirmation with counts, corruption recovery copies and protection from conflicting-tab overwrites.
- Short-course startup uses a compact course collection. Dictionary, full corpus, classifications, expressions and family data load on demand. Optional collections use content-addressed filenames.
- Explicit offline downloads, availability checks, timeout/error responses, scope-specific cache cleanup and an update prompt.
- Keyboard focus restoration, route focus, Urdu bidi/font handling, reduced-motion and narrow-screen refinements.

## Reproduce and test

Use Python 3 and Node.js (no third-party dependencies):

```sh
python3 scripts/build-communication.py
python3 scripts/version-packs.py
python3 scripts/validate.py
node tests/qa.cjs
node tests/revision.cjs
node tests/offline.cjs
```

`build-communication.py` preserves assigned word IDs and reads the authored rows in `scripts/communication-course.txt` plus the separate practice sentences. `version-packs.py` produces deterministic content-addressed optional JSON packs. The lexical correction data is already committed in the JSON files. Do not rerun old import-generation scripts over this edition without reviewing their output: they predate the resolver and can undo corrections. `scripts/revise.py` records the earlier correction pass; the current committed family JSON additionally corrects commuting relationships.

The previous complete test scripts are retained under `tests/legacy/` as historical fixtures with pre-migration assumptions. `qa.cjs` retains and adapts the legacy functionality checks. Startup/studio compatibility entry points run the consolidated integration suite rather than executing those obsolete assumptions. See `reports/verification.md` for exact checks and limitations.

When changing deployed code or essential JSON, increment the worker version in `sw.js` and the matching optional-cache version in `modules/packs.js`. Deploy the full repository atomically. Content-addressed optional packs prevent silently serving a new pack under an old URL; an unavailable old pack fails clearly. Do not publish an incomplete upload.

## Data and licences

The code licence does not automatically license imported data. Retain `LICENSE.txt`, `WORDNET_LICENSE.txt`, publisher/source attribution, source quotes and import audits. Publisher filters mean traceable source occurrence, not that a publisher wrote or verified a Wordcraft teaching definition. New communication lessons carry original Wordcraft provenance and no publisher endorsement. Confirm reuse permissions before redistributing third-party collections under another licence.

Progress is local. No cross-device sync, AI grammar grading, pronunciation assessment or pilot outcome is claimed. See `docs/progress-and-backups.md`, `docs/editorial-and-pilot.md` and `CHANGELOG.md`.
